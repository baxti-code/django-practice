# 03 - Templates

Learning Django Templates and Template Language (DTL).

## Topics Covered
- Setting up the templates directory
- Rendering HTML with `render()`
- Passing dynamic data via context
- `{{ variable }}` — displaying values
- `{% for %}` — looping through lists
- `{% if %}` — conditional rendering

## Getting Started

```bash
python manage.py runserver
```
